# Priyanka Chicken Hotel Website

A responsive restaurant website built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — menu filtering and mobile navigation

## Run locally

Open `index.html` in Chrome, Edge or Firefox.

## Customize before publishing

In `index.html`, replace:

- `Your Hotel Address`
- `Your City, Maharashtra`
- `+91 99999 99999`
- WhatsApp number in the `wa.me` link
- Opening hours

In `script.js`, edit the `menuItems` array to change dish names, descriptions and prices.

The current dish prices are sample/demo values.
